Logg inn som administrator

Bruk kontoen som er registrert som administrator i Supabase. Ingen passord lagres på denne nettsiden.

📦 Ting-ID-bestillinger

Viser bestillinger fra Supabase. Du kan oppdatere status og arkivere testbestillinger uten å slette brikkekoder. Arkiverte bestillinger skjules som standard.

🐕 Hunde-ID og 🐈 Katte-ID

Disse bestillingene kobles til senere når vi har bekreftet hvilke databasetabeller som lagrer selve ordrene. Vi viser ikke registrerte dyr som om de var bestillinger.
